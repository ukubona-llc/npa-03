06 — Scalar · The decision · And who controls it

One answer.
Government holds the keys.

Every compression of the tensor — every colour on the map, every dropdown choice, every pipeline update — collapses to a single actionable number. And that number, and all the data behind it, belongs to Government.

Data Sovereignty · Uganda Data Protection & Privacy Act 2019
Whoever holds the API keys
controls the data.
In this model, the keys stay with Government.
What Government owns
All 146 district data streams. All indicator values. All historical records. Stored in a government-controlled repository — NPA holds the credentials, not Ukubona.
What is rented
Compute only. The Ukubona engine runs calculations on cloud infrastructure — AWS / Azure / NITA-U — but the data returns immediately to the sovereign store. The compute is rented; the data is sovereign.
The legal frame
Uganda's Data Protection and Privacy Act (2019) requires demonstrable access controls. This model satisfies that requirement. Aggregated district indicators, not individual identities. Visibility, not surveillance.
The Ukubona role
Ukubona LLC maintains the engine — the compressor. The data is NPA's. If NPA ends the contract, the data stays with Government. The twin is a service, not a dependency.
